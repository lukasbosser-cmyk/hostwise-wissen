# hostwise-wissen – Hinweise für Claude

Dieses Repo ist das Obsidian-Vault des hostwise-Teams (Lukas, Oskar, Maximilian). Code liegt nicht hier, sondern in `hostwisedemo`.

- Deutsch, einfache Sprache, ganze Sätze. Keine Fachbegriffe ohne Erklärung.
- Notizen sind Markdown mit Frontmatter (`tags`, `stand`), Links als Obsidian-Wikilinks `[[Notizname]]`, Hinweise als Callouts (`> [!info]`, `> [!warning]`). Diagramme als Mermaid.
- Ablage: `01 Projekt`, `02 Kunden und Markt`, `03 Technik`, `04 Präsentationen`. Bilder unter `03 Technik/Bilder`.
- Notiznamen sind im ganzen Vault eindeutig, sonst lösen Wikilinks falsch auf.
- Ist eine Notiz die Kopie eines Claude Docs, steht oben ein Callout mit dem Link zum Original. Bei Änderungen am Doc die Kopie mitziehen.
- Neue Entscheidungen oben in `01 Projekt/Entscheidungen.md` mit Datum eintragen.
- Simulierte Interviews und Personas bleiben als simuliert bzw. als Hypothese gekennzeichnet.
- Niemals Passwörter, API-Schlüssel oder personenbezogene Daten von Gastgebern oder Gästen ablegen.
