# hostwise-wissen

Das gemeinsame Wissen von hostwise: Pflichtenheft, Kundenforschung, Technik und Präsentationen. Gelesen und bearbeitet wird es in **Obsidian**, gespeichert und geteilt über dieses private GitHub-Repo. Claude schreibt neue Dokumente direkt hier hinein.

## Inhalt

| Ordner | Was drinsteht |
| --- | --- |
| `01 Projekt` | [[Pflichtenheft]], [[Kursplan und Termine]], [[Entscheidungen]] |
| `02 Kunden und Markt` | [[Vermieter-Perspektiven und User Stories]], [[Simulierte Interviews]] (mit Word-Fassungen), [[Marktdaten-Anbieter]] |
| `03 Technik` | [[hostwise engine]], [[Tools und Konten]], [[Kostenlose MCPs]], [[Bau-Prompt Grundgerüst]] |
| `04 Präsentationen` | Decks als PowerPoint und PDF, Übersicht in [[Präsentationen]] |

Am besten startet man mit dem [[Pflichtenheft]] und den [[Entscheidungen]].

## Einrichten (einmal)

1. **GitHub Desktop** installieren und mit dem eigenen GitHub-Konto anmelden. Lukas lädt Oskar und Maximilian unter Settings → Collaborators ins Repo ein.
2. In GitHub Desktop **File → Clone repository** wählen, `lukasbosser-cmyk/hostwise-wissen` aussuchen und einen Ordner festlegen, z. B. `Dokumente\hostwise-wissen`.
3. **Obsidian** öffnen, **„Open folder as vault“** wählen und genau diesen Ordner nehmen.
4. Fertig. Links in doppelten eckigen Klammern wie [[Entscheidungen]] springen direkt zur Notiz.

## Arbeiten (jedes Mal)

1. **Vorher:** in GitHub Desktop auf **„Fetch origin“** und dann **„Pull origin“** klicken, damit ihr den neuesten Stand habt, auch das, was Claude geschrieben hat.
2. In Obsidian lesen und schreiben.
3. **Nachher:** in GitHub Desktop eine kurze Beschreibung eintragen, **„Commit to main“** und **„Push origin“** klicken.

Wer lieber nichts von Hand synchronisiert, kann in Obsidian das kostenlose Community-Plugin **„Git“** installieren und automatisches Pull und Push alle paar Minuten einschalten.
